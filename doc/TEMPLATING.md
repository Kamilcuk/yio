This project is templated with jinja2 with python.

The content of the ./src/yio/yio directory is being templated, depending on MODE.

Currently, there is 1 mode: yio.

- `yio`
  - normal mode
  - `TCHAR` is `char`
  - `TSTRCHR` is `strchr`
  - etc.
  - `TMODE` is `1/*TMODE*/`
  - `TMODEX` is `1/*TMODEX*/`
  - `TMODEN` is `1`

The files are generated by CMake into BINARY_DIR, and then compiled. All files have to be generated
before any compilation. The script is in [src/preprocess.py](src/preprocess.py).

All files are scanned for `YYIO_ERROR` invocations. Any such invocations are collected into
`yio_error_genmsg.h` and `yio_error_genenum.h` files by `src/geterrors.py` script and then added
with strings as errors.
